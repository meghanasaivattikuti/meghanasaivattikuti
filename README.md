### Recent work

**[SandboxScope](https://github.com/meghanasaivattikuti/SandboxScope)** — Ask a plain-language question about a CSV, review the Python the model writes, then run it in an isolated Vercel Sandbox with outbound network denied. Generated programs are signed server-side, so only code the app produced can execute, and every run returns a receipt showing runtime, network policy, duration, and cleanup.
`Next.js` `AI SDK` `AI Gateway` `Vercel Sandbox` `TypeScript`

**[Migration Readiness Advisor](https://github.com/meghanasaivattikuti/migration-advisor)** — Assesses an enterprise's current AWS deployment and generates a phased Vercel migration architecture: what moves and what stays, IaC guidance, a SOC 2 / PCI DSS / HIPAA compliance mapping, and a rollout plan. → [Live](https://migration-advisor.vercel.app)
`Next.js` `AI SDK` `Terraform`

**[PDD Modernization Demo](https://github.com/meghanasaivattikuti/tech-demo)** — A modernized architecture for a public disciplinary database lookup tool, inspired by real sports-safety databases. All data is fictional. → [Live](https://tech-demo-inky.vercel.app)
`Next.js` `SQL Server` `AI Gateway`

**[CrawlSpace](https://github.com/meghanasaivattikuti/eve)** — Audits a site across three areas: whether it is readable by AI agents and crawlers (`llms.txt`, `AGENTS.md`, robots rules for GPTBot / ClaudeBot / PerplexityBot), SEO fundamentals, and HTTP security headers. → [Live](https://eve-virid-eight.vercel.app)
`Agents` `SEO` `Web security`
